# CLAUDE.md — MyDictate

Нативное macOS-приложение для голосового ввода (локальное распознавание WhisperKit
+ опц. AI-обработка и перевод). Полное описание — в **[spec.md](./spec.md)**.

## ⚠️ Главное правило: держать spec.md в актуальном состоянии

`spec.md` — единый источник правды по приложению. **При любом изменении
функциональности обязательно:**

1. **Перед работой** перечитай `spec.md` — свериться с архитектурой, границами
   модулей и принятыми решениями (не дублировать, не противоречить).
2. **После изменения** обнови `spec.md`:
   - добавил функцию/модуль/настройку → внеси в соответствующие разделы
     (возможности, архитектура, ключи UserDefaults, пайплайн);
   - удалил/изменил поведение → убери/поправь устаревшее (не накапливать мусор);
   - изменил решение или поймал важную граблю → отрази в журнале (§12);
   - затронул границы ядро / блок A (LLM) / блок B (перевод) → обнови §6/§7/§13,
     чтобы инструкции «как вырезать» оставались верными.
3. Спецификация должна точно соответствовать коду — **никаких расхождений**.
   Если правишь код, но забыл спеку — работа не закончена.

Держи структуру модулей чёткой: **ядро** (распознавание/вставка/хоткей/индикатор/
история) обязательно; **блок A (LLM, LM Studio)** и **блок B (язык/перевод)** —
вырезаемые. Новый функционал относи к правильному слою и помечай в spec.md.

## Сборка и запуск

```bash
./scripts/create-cert.sh        # один раз: стабильная подпись (права не слетают)
swift build                     # быстрая проверка компиляции
./scripts/build-app.sh release  # сборка .app + подпись сертификатом
open MyDictate.app
```

- Среда: только **Command Line Tools** (без Xcode). Apple Silicon, macOS 13+.
- Отладка распознавания без микрофона:
  `./MyDictate.app/Contents/MacOS/MyDictate --selftest <audiofile>`
  (тестовое аудио — `say -v Milena -o /tmp/t.aiff "текст"`; **английским голосом
  русский текст не тестировать** — даёт транслитерацию).

## Подпись и права (важно)

- Подписывать **только** сертификатом «MyDictate Self-Signed» (`build-app.sh`
  делает это сам). Ad-hoc подпись меняет cdhash при каждой пересборке → слетает
  «Универсальный доступ». При смене подписи: `tccutil reset Accessibility
  com.mydictate.app` и заново выдать доступ + перезапуск.
- Права: Микрофон + Универсальный доступ (триггер правый ⌥ и вставка ⌘V).

## Модель распознавания

- WhisperKit качает Core ML-модели в `~/Documents/huggingface/models/argmaxinc/…`.
- Встроенный загрузчик иногда виснет (xet HF) → `scripts/fetch-whisperkit-model.sh`.

## Заметки для агента

- Не возвращай зависимости `SwiftWhisper`/`KeyboardShortcuts` (были удалены: CPU-краш
  на 128-мел и `#Preview`-несовместимость с CLT-сборкой соответственно).
- LM Studio (блок A) — внешняя зависимость пользователя; нельзя делать её
  обязательной для ядра.
- Перевод в не-английский язык требует блока A (Whisper умеет только →en).
