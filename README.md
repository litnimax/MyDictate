# MyDictate

Нативное приложение для голосового ввода на macOS. Нажимаете правый ⌥ (или иконку
в меню-баре) → говорите (виден индикатор записи) → ещё раз правый ⌥ → текст
распознаётся **локально** на GPU/Neural Engine (WhisperKit) и вставляется в
активное поле ввода.

## Возможности

- 🎙 Запись голоса с плавающим индикатором (пульсирующая точка + уровень звука, кнопки паузы и отмены)
- ⌨️ Глобальный триггер — **правый ⌥ (Option)** + иконка в меню-баре
- 🧠 Локальная транскрибация **WhisperKit (Core ML, GPU + Apple Neural Engine)**, модель `large-v3-turbo` — без отправки данных в облако
- ✨ Необязательная AI-чистка текста локальной LLM в LM Studio (пунктуация, заглавные)
- 📖 Словарь замен терминов (напр. «оду флоу» → «Oduflow») — в «Настройки…»
- 📋 Автовставка распознанного текста в текущее поле (через буфер + ⌘V)
- 🌍 Выбор языка распознавания (авто / ru / en / uk / pl / de / es / fr)

## Сборка

Нужны только **Command Line Tools** (полноценный Xcode не требуется).

```bash
# 1. (один раз) Создать стабильную подпись — чтобы «Универсальный доступ»
#    не слетал при пересборках
./scripts/create-cert.sh

# 2. Собрать приложение
./scripts/build-app.sh release

# 3. Запустить
open MyDictate.app
```

Модель распознавания скачивается **автоматически** при первом запуске (WhisperKit
тянет готовые Core ML-модели с Hugging Face в `~/Documents/huggingface/models/argmaxinc`).
Менять модель — в «Настройки…» (large-v3-turbo / large-v3 / small / base).
Старый скрипт `download-model.sh` (ggml-модели whisper.cpp) больше не нужен.

### Стабильная подпись

`create-cert.sh` создаёт самоподписанный сертификат «MyDictate Self-Signed» и
кладёт его в login-keychain. `build-app.sh` подписывает им приложение, поэтому
designated requirement привязан к сертификату, а не к контрольной сумме файла —
и выданные права (Микрофон, Универсальный доступ) переживают пересборки.
Без сертификата сборка падает обратно на ad-hoc подпись.

## AI-обработка текста (LM Studio) — опционально

Распознанный текст можно автоматически чистить локальной LLM в LM Studio
(пунктуация, заглавные, удаление слов-паразитов). Whisper по-прежнему делает
само распознавание — LM Studio лишь причёсывает результат.

1. Установите LM Studio и загрузите текстовую модель (напр. `google/gemma-4-e4b`).
2. Запустите локальный сервер: `lms server start` (или кнопкой в «Настройки…»).
3. В «Настройки…» включите «Чистить текст через LM Studio».

Если сервер недоступен — вставляется сырой текст Whisper, ничего не ломается.

## Разрешения (выдаются при первом запуске)

1. **Микрофон** — запрашивается автоматически при первой записи.
2. **Универсальный доступ (Accessibility)** — нужен, чтобы вставлять текст в
   активное поле. Системные настройки → Конфиденциальность и безопасность →
   Универсальный доступ → включить **MyDictate**.

> Глобальный хоткей работает без Accessibility (используется Carbon
> `RegisterEventHotKey`). Accessibility нужен только для автовставки текста.

## Как пользоваться

1. Поставьте курсор в любое текстовое поле (заметки, браузер, мессенджер…).
2. Нажмите **⌘⇧D** — появится индикатор «Запись…».
3. Говорите.
4. Нажмите **⌘⇧D** ещё раз — индикатор сменится на «Распознаю…», затем текст
   вставится в поле.

Устройство записи, модель и язык меняются в меню-баре → «Настройки…».

## Архитектура

| Файл | Назначение |
|------|-----------|
| `AudioRecorder.swift` | Захват с микрофона, ресемпл в 16 кГц mono Float32, метрика уровня |
| `Transcriber.swift` | Локальная транскрибация через SwiftWhisper (whisper.cpp) |
| `TextInjector.swift` | Вставка текста в активное поле (буфер + эмуляция ⌘V) |
| `RecordingIndicator.swift` | Плавающий HUD-индикатор (SwiftUI) |
| `Shortcuts.swift` | Глобальный хоткей через Carbon `RegisterEventHotKey` |
| `AppDelegate.swift` | Меню-бар и конечный автомат `idle → recording → transcribing` |
| `SettingsView.swift` | Окно настроек (хоткей, язык) |
